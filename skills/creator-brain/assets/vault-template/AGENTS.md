这是用 creator-brain 搭的自媒体知识库。任何 AI 进入这个文件夹工作时，先读这份文件，再读 `INDEX.md` 和 `本周.md`。

## 工作规则

1. **人做决定**：选题方向、标题和开头、脚本终稿、任何对外发布，都要先给用户看、等用户点头。
2. **数字有来处**：写进来的数字都要注明来源（链接 / 截图 / 口述 / 日期）。看不清就留空写"待确认"，不要估。
3. **原件不动**：已有文件不移动、不改名、不覆盖、不删除；确实要动，先列清单问用户。同一份内容只留一个当前版本，旧版放 `_旧版/`。
4. **分清四种内容**：事实、别人的观点、用户的判断、AI 的推断，分开写。
5. **不碰隐私**：不读 `.env`、Cookie、密码、token 类文件；不记录粉丝的私人联系方式。
6. **留痕**：改动知识库后在 `system/日志.md` 追加一行；新经验写进 `09.我的方法论/我的爆款规则.md`；更新 `本周.md`。
7. **表格不给用户填**：`02.对标库/数据/作品.csv` 和 `07.发布与复盘/发布记录.csv` 由 AI 根据用户给的链接、截图、口述来记，记完用一句人话复述给用户确认。

## 各文件夹放什么

| 文件夹 | 放什么 |
|---|---|
| `00.收件箱/` | 还没整理的东西，先扔这里 |
| `01.账号定位/` | 我是谁、做什么、给谁看、怎么说话 |
| `02.对标库/` | 对标账号卡、作品数据、爆款拆解、选题验证报告 |
| `03.用户洞察/` | 粉丝的问题、评论、私信里的需求 |
| `04.素材库/` | 案例、数据、金句、图片，可直接用进视频 |
| `05.选题池/` | 每个选题一张卡，带依据和状态 |
| `06.内容生产/` | 脚本草稿和定稿 |
| `07.发布与复盘/` | 发布记录、数据、每条的复盘结论 |
| `08.私域与转化/` | 私域规划、引流记录、后端产品 |
| `09.我的方法论/` | 自己总结出来、有数据支持的规律 |
| `system/` | 关于我、日志、选题分类、健康状态 |

需要 creator-brain 的详细做法时，读已安装的 creator-brain Skill。
