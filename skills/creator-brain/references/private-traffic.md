# 私域引流

目标：让看完视频、觉得有用的人，有一个自然的理由留下来（关注、进群、加好友），以后能持续联系。

## 先想清楚三件事

1. **送什么**：和这条内容直接相关、看完马上想要的东西。比如教程的完整文档、用到的模板、Skill、提示词合集、资源清单。越具体越好，"干货大礼包"不如"这条视频里的 5 个提示词"。
2. **在哪接住**：粉丝群、私信、公众号、个人微信。选一个主阵地，别全开。
3. **之后干什么**：群里/私域里持续给什么、最后卖什么（课程、陪跑、服务、工具）。前端内容和后端产品对得上，私域才有价值。

答案写进 `08.私域与转化/私域规划.md`。

## 常见手段

| 手段 | 怎么做 | 风险和注意 |
|---|---|---|
| 评论区关键词 | 视频结尾说"评论区扣 XX 领资料"，用私信自动回复或手动发 | 评论数会明显变多；回复要及时 |
| 免费送自己做的工具/Skill/模板 | 视频演示效果，资料放在群里或主页能找到的地方 | 东西要真能用，坏口碑传得快 |
| 粉丝群 | 主页、视频挂粉丝群入口，"资料在群公告里" | 平台内功能，最稳；需要定期维护 |
| 长教程配完整文档 | "配套文档已整理好"，引到公众号或群 | 文档要比视频更完整，才有动力去拿 |
| 公开进度/连载 | "这是第 3 期，完整进度在群里同步" | 适合长期项目，要能坚持更新 |
| 直播 | 直播间答疑，引导加群 | 需要固定时间 |

## 平台规则提醒

- 抖音、视频号对视频和评论里直接放微信号、二维码、"加 V"管得严，容易限流；优先用平台内的粉丝群、私信、主页功能。
- 谐音、拆字、表情代替也容易被识别，不建议。
- 每次用新的引流方式前，按 precheck.md 的"引流方式"一节查一遍。

## 记录效果

每条视频用了什么引流方式、带来多少人（进群人数、私信数、领取数），记在 `08.私域与转化/引流记录.md`，一行一条：日期｜视频｜方式｜送了什么｜带来多少人。用户问"哪种引流最有效"时，从这里算。
