# 基于知识库回答问题

用户问"我之前记过 XX 吗""我的对标里谁做过 XX""根据我的资料写个 XX"时，先查库再回答。

## 步骤

1. 读 `INDEX.md` 和相关目录的 `_索引.md`，判断该去哪里找。
2. 用检索脚本找关键词：

   ```bash
   python scripts/search.py --root "<知识库>" "关键词1 关键词2" --limit 20
   ```

   它返回 `文件:行号` 和那一行的内容。挑最相关的几个文件打开读。
3. 回答时：
   - 每个事实后面标出处：`（见 02.对标库/账号/XX.md）`；
   - 库里没有的内容，明确说"知识库里没有记录"，再决定要不要用 AI 自己的知识补充，补充的部分标"库外信息"；
   - 多个来源说法不一样时，把不同说法都列出来，并说明各自来源和日期。
4. 这个回答以后还会用到（比如一份对比分析、一个总结），问用户"要不要存进知识库"。同意就存到合适的目录，按 ingest.md 的格式写来源卡，来源写"基于知识库整理"。

## 不要做的

- 不要为了回答问题去改原有笔记。
- 不要把 AI 的推断写成用户的判断。
