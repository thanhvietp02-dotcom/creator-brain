# 资料接入

把零散的东西（文章、视频逐字稿、截图、录音、灵感、聊天里的一句话）变成以后能找到、能用上的笔记。

## 流程

1. **收**：用户发来的东西，或 `00.收件箱/` 里的文件。看不懂的格式（视频、录音）先问用户有没有文字版；AI 自己能转文字的话先转。
2. **分**：判断它属于哪一类，放进对应目录：

   | 是什么 | 放哪 |
   |---|---|
   | 对标号的视频、逐字稿、评论 | `02.对标库/拆解/` |
   | 粉丝留言、私信里的问题、用户的困惑 | `03.用户洞察/` |
   | 可以用在视频里的案例、数据、金句、图片 | `04.素材库/` |
   | 一个"可以拍"的想法 | `05.选题池/`（按 topics.md 的选题卡写） |
   | 方法、经验、别人的方法论 | `09.我的方法论/` |
   | 拿不准 | 留在 `00.收件箱/`，在文件开头写一句"待归类：原因" |

3. **写**：每条资料写成一张笔记，开头放"来源卡"：

   ```markdown
   ---
   来源: <链接或文件路径>
   作者: <谁说的/谁做的>
   日期: <发布日期>  记录: <今天>
   类型: 事实 | 观点 | 我的判断 | AI 推断
   ---
   ```

   正文先写 3 行以内的"一句话要点"，再写细节。别人的观点注明"XX 认为"，不要写成事实。
4. **连**：笔记里提到的账号、选题、方法，用 `[[笔记名]]` 链接到已有笔记；同一件事已经有笔记，就补充到原笔记里，不新建重复的。
5. **记**：更新所在目录的 `_索引.md`（一行一条：笔记名 + 一句话），在 `system/日志.md` 记一笔。

## 原件怎么处理

- 用户发来的文件：原件放 `00.收件箱/原件/` 或用户指定的位置，笔记里写原件路径。
- 用户硬盘上已有的文件：不移动，笔记里写原路径。
- 很长的原文（逐字稿、长文章）：原文单独存一个文件，笔记只放要点和引用。

## 收件箱清理

用户说"整理收件箱"时：按上面流程逐个处理，最后告诉用户"处理了 N 个，归到了哪里，还剩 M 个拿不准的"，列出拿不准的让用户决定。
