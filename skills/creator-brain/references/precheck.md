# 发布前检查

在用户发布前，按清单逐项检查标题、封面文字、口播稿/字幕、简介、评论区置顶和引流话术。这不是平台的官方规则，是常见风险的提醒；平台规则会变，拿不准的以平台最新公告为准。

## 输出格式

按风险从高到低列出，每条写：在哪（标题 / 第几句 / 封面）→ 原文 → 风险等级 → 为什么 → 改成什么。

| 等级 | 意思 |
|---|---|
| 必须改 | 很可能违规、被限流或下架 |
| 建议改 | 有一定风险，或会显得夸大 |
| 可以不改 | 小问题，用户自己决定 |
| 通过 | 没发现问题 |

最后给一句总结："有 2 处必须改，1 处建议改，其余通过。"

## 检查清单

### 1. 夸大和绝对化
- 极限词："最""第一""唯一""全网""100%""永久""顶级"等，尤其和产品、效果连用时。
- 效果承诺："保证涨粉""月入过万""一周学会"等无法兑现的承诺。
- 收益展示：晒收入、晒流水，暗示跟着做就能赚钱。

### 2. 引流方式（抖音、视频号尤其严）
- 直接写微信号、手机号、二维码、"加 V""私我拿"等站外导流字样。
- 谐音、拆字、表情代替（"薇""V❤"）也容易被识别。
- 更稳的做法：评论区关键词 + 私信自动回复、粉丝群、主页简介里的平台内功能。详见 private-traffic.md。

### 3. 版权和授权
- 背景音乐：是否用平台曲库或有授权。
- 别人的视频片段、截图、图片：是否注明来源、是否超出合理引用。
- 字体：商用字体是否有授权。

### 4. 敏感领域
- 医疗健康、金融理财、法律、教育资质类内容：是否需要资质，是否给出了具体诊断、投资建议。
- 涉及政治、宗教、民族、灾难事件：建议避开。
- 未成年人出镜、隐私信息（别人的脸、聊天记录、手机号）：需打码或取得同意。

### 5. AI 内容
- 用 AI 生成的人像、声音、画面：按平台要求标注"AI 生成"。
- 模仿真人声音、形象：需要本人授权。

### 6. 广告和推广
- 收了钱或有合作的内容：按平台要求标注广告/合作。
- 带货：视频里说的、商品页写的、口播承诺的三者要一致。

### 7. 标题和封面
- 标题党：标题承诺的内容视频里有没有兑现。
- 封面文字：和标题一致，手机上能看清（建议不超过 12 个字）。

检查结果写进对应选题卡末尾的"发布前检查"一节，用户改完后可以再查一次。
